## Panel de Administración — Demo en Vivo

Prueba la aplicación completa directamente en el navegador:

**>>> https://admin-panel-frontend-production-dce7.up.railway.app**

### ¿Qué puedes hacer?

- Registrarte e iniciar sesión con tu propio usuario
- Crear, editar y eliminar ítems (título, descripción e imagen opcional)
- Buscar ítems por título o descripción
- Exportar el listado de ítems a archivo CSV
- Ver los usuarios registrados en el sistema

### Stack tecnológico

- **Frontend:** React + TypeScript + Vite
- **Backend:** Node.js + Express + SQLite
- **Autenticación:** JWT con contraseñas encriptadas (bcrypt)
- **Pruebas:** 16 pruebas automatizadas con Jest y Supertest
- **Despliegue:** Railway (backend y frontend)
